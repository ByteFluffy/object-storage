# 还值得做的事

图片、音视频、探测、清理和两个云驱动都已经有本地实现和测试。下面只留还值得投入的项。

## 值得做

- 把插件和 TOS/S3 挂进 `package.json` 的 `exports`。现在公开入口只有根、浏览器和内存驱动，调用方只能靠源码相对路径使用插件。
- 收紧探测。`checkObject` 在校验算法不同时会报内容不符。没有 SHA-256 预算时，不能只凭对象存在就通过。HEAD 必须带匹配的签名方法，200 不能代替 GET 正文。
- 收紧清理。`cleanObjects` 应核对 `storageId`。单次删除失败应记下该项并继续。只对调用方登记的 `uploadId` 终止分片，不按前缀扫描全桶。
- 桶写入探针加上 `ifNoneMatch: '*'`。冲突时失败，并且不要删除已有对象。
- 入口测试改为检查构建后的 `dist/index.js` 导入图，避免 Sharp 或云 SDK 被间接打进根入口。
- 真实桶测试。需要单独授权的桶、地域和测试前缀。本地假客户端不能代替这一项。
- 发布前决定许可证、公开包名，以及个人仓库镜像到 `starrank-soft` 的方式。npm 发布仍是单独任务。

## 现在不做

- 再做一个封存插件。封存已经在 `Storage.finalize`。
- 包内长轮询、数据库、Restate 或固定流水线。
- ZIP、HEIC、SVG、字幕、时间线、测速选区、任意 FFmpeg 命令。
- 为了编排速度换成 Go 或 Rust。
